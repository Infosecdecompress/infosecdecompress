# Security Policy

This repository contains the source of [infosecdecompress.com](https://infosecdecompress.com). If you find a vulnerability in the site or its build pipeline, please report it privately rather than opening a public issue.

## Reporting

- **Contact:** contact@infosecdecompress.com
- **Preferred languages:** English, 繁體中文 (zh-Hant-TW)

Please include the affected URL or file, steps to reproduce, and the impact you observed. We aim to acknowledge reports within a few days.

## security.txt

The machine-readable policy is published at <https://infosecdecompress.com/.well-known/security.txt> and generated at build time by `gatsby-plugin-security-txt` (see `gatsby-config.ts`). Keep the two in sync when either changes.
